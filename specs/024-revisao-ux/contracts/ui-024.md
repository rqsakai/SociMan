# Contrato de UI: 024 (componentes, rotas e nomes acessíveis)

Os e2e dependem destes nomes. Mudou aqui, mudou o teste.

## Rotas
| Endereço | Comportamento |
|---|---|
| `/app/aprendizado?perfil=&aba=&conta=&medida=` | página do Aprendizado (grupo Analytics) |
| `/app/perfis/:id/aprendizado?…` | `Navigate replace` → `/app/aprendizado?perfil=:id&…` (preserva `aba`, `conta` e `medida`) |
| `/app/perfis/:id?aba=cortes` | `Navigate replace` → `/app/conteudos?perfil=:id` |
| `/app/conteudos?pagina=&tamanho=` | página numerada (padrão `tamanho=25`) |

## Menu (`nav[aria-label="Menu principal"]`)
- Grupos: um botão com o nome do grupo ("Cortes", "Analytics", "Configurações"), com `aria-expanded` e
  `aria-controls`; os itens ficam numa lista aninhada.
- Os rótulos dos itens não mudam (os e2e usam `getByRole("link", { name, exact: true })`). Novo item:
  "Aprendizado".
- O helper `nav(page, label)` (`e2e/helpers.ts`) abre o grupo pai se `aria-expanded="false"`.

## Componentes alterados
- `HeaderCard`: invólucro `pt-6`, faixa `-mt-6`, corpo `px-5 pt-4 pb-5`; sem `mt-6`. O `tone` padrão é `primary`.
- `Card` (`ui/card.tsx`): `gap-4 py-5`, `px-5`.
- `Tabs`: `gap-6` padrão.
- `DataTable`: `emptyMessage: ReactNode`, prop `empty` (EmptyState); `search` só para dados locais.
- `AppShell`: o conteúdo fica em `mx-auto w-full max-w-[1440px]`.
