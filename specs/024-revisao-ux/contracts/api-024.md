# Contrato da API: mudanças aditivas da 024

Todas as mudanças são **aditivas**: nenhum campo some, nenhum parâmetro passa a ser obrigatório e nenhum
operationId é novo. Depois de mudar, rodar `npm run gen:contract`. O `check:contract` compara o `openapi.json`
e o `mcp-tools.json`.

| operationId | Mudança | MCP |
|---|---|---|
| `envios_list`, `envios_get` (e toda resposta com `Envio`) | `Envio.cortesResumo: CortesResumo \| null` | já é TOOL de leitura; o campo novo entra no `outputSchema` |
| `videos_fonte_list` | `VideoFonte.afinidade.temas: TemaCasado[]` (padrão `[]`); `VideosList.afinidadeEstado: AfinidadeEstado \| null` | TOOL de leitura |
| `conteudos_list` | query `offset: int ≥ 0` (opcional). Com `cursor` junto → **400** `paginacao_invalida` | TOOL de leitura; `offset` vira entrada da tool |
| `anotacoes_list` | query `q: str` (1..100, opcional), busca em `texto` sem acento e sem caixa | TOOL de leitura; `q` vira entrada da tool |

## Schemas novos (camelCase no JSON)

```text
CortesResumo   { aceitos: int, pendentes: int, falhou: int, arquivados: int }
TemaCasado     { temaId: uuid, nome: str, pontos: float, acao: "ampliar"|"cortar"|null, decisivo: bool }
AfinidadeEstado{ ativa: bool, motivo: "sem_perfil"|"sem_temas"|"desatualizada"|"neutra"|null }
```

## Erros
- `400 paginacao_invalida`: "Use `offset` ou `cursor`, não os dois." (`conteudos_list`).

## Testes de contrato (pytest)
- `envios`: uma geração com cortes em cada estado → contagens exatas; geração sem cortes → `null`; arquivar
  um corte muda a contagem na leitura seguinte.
- `videos_fonte_list`: vídeo com 2 temas casados → `temas` com 2 itens e o decisivo primeiro; perfil sem
  taxonomia → `afinidadeEstado.motivo = "sem_temas"` e `temas = []`; a soma das parcelas (4 da 006, ×0,3 de já
  cortado e afinidade) bate com o `score` (±1). O `test_aprendizado_descobrir.py:62` (resposta neutra igual à de
  antes) continua passando.
- `conteudos_list`: `offset` 0, 25 e 50 com `limit=25` cobrem o mesmo conjunto que o cursor, sem repetir nem
  pular; `offset` + `cursor` → 400; `offset` além do total → `items=[]` e `total` certo.
- `anotacoes_list`: `q` acha por trecho sem acento; vazio ou só espaços → igual a hoje; > 100 caracteres → 400 `validation_error`.
- `test_mcp_mapa.py`: sem mudança nas contagens (nenhuma operação nova).
